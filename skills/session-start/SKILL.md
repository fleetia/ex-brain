# Session Start

지식 vault(`~/KnowledgeBase`)의 태스크 기록에서 이전 세션의 컨텍스트를 복원한다.

## Workflow

### 1. 진행 중 태스크 확인

- 사용자가 태스크 파일명을 지정했으면 `00.memory/tasks/in-progress/{파일명}`을 읽는다.
- 지정하지 않았으면 `00.memory/tasks/in-progress/` 목록을 확인한다:
  - 1개면 바로 사용
  - 여러 개면 목록을 보여주고 어떤 작업을 이어갈지 묻는다
  - 비어 있으면 "진행 중인 태스크가 없습니다"라고 안내하고, 최근 `done/` 파일 2~3개를 참고로 보여준다

### 2. 태스크 파일 읽기

- 태스크 파일 전체를 읽고 frontmatter(`status`, `work-dates`)와 `## 미완료`, `## 과정 노트`를 파악한다.

### 3. 관련 지식 조회 (1회)

- 태스크 제목과 핵심 키워드로 `kb-lookup` skill의 검색 동작을 수행한다.
- 매칭 문서가 있으면 요약 마지막에 `### 관련 문서` 섹션으로 경로 + 한 줄 요약을 붙인다. 없으면 섹션을 생략한다.
- 이 검색으로 해당 태스크의 kb-lookup은 완료된 것으로 간주한다 — 이어지는 본 작업에서 같은 주제를 다시 검색하지 않는다.

### 4. 컨텍스트 요약 출력

```
## 세션 시작: {태스크 제목}

**상태**: {status}
**작업 일자**: {work-dates}

### 미완료 작업
{## 미완료 섹션 내용}

### 관련 문서
{있을 때만}

---
이 작업을 이어서 진행할까요?
```

### 5. 사용자 확인 후 작업 시작

## Edge Cases

| 상황 | 처리 |
|---|---|
| in-progress 태스크 없음 | 안내 후 최근 done 참고 표시, 새 작업으로 진행 |
| 지정한 파일명이 없음 | in-progress 목록을 보여주고 다시 선택 요청 |
| 태스크 파일에 `## 미완료` 없음 | `## 작업 내용` 기준으로 요약 |
